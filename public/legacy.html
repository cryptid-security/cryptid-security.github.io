Fifteen instruments. No runtime dependencies. Every one runs offline, ships with its own tests, and gives a result you can check by hand.

Malware Analysis & Reverse Engineering

05

Pull a config from a live RAT, find code that was injected or hollowed in, unpack a dropper, judge a driver.

unmask
Config extractor for the AsyncRAT / DcRat / VenomRAT family — decrypts and HMAC-verifies the embedded settings.
kira-scan
PE triage with a pure-Python YARA engine: strings, conditions, and the pe, math, and hash modules.
ghost-hunter
Live memory scanner that finds injected and hollowed code by walking thread stacks.
unwrap
Unpacks .lnk, .hta, and HTML-smuggling droppers to the staged payload, without executing it.
driver-guard
Analyses vulnerable drivers (BYOVD) and flags the arbitrary read, write, and process-kill primitives attackers abuse.

Forensics & Threat Intelligence

03

Hunt through logs and captured traffic, and turn a written report into structured intelligence.

evtx-hunter
Windows Event Log hunter with its own Sigma engine — correlates bursts and decodes obfuscated PowerShell.
panoptes
Reads a packet capture and detects RAT and Cobalt Strike certificates, DNS-over-HTTPS, and suspicious TLS.
ioc-hunter
Turns a threat report into clean, defanged indicators and a STIX 2.1 bundle, entirely in the browser.

Application & Supply-Chain Security

05

Audit the headers, the email posture, the shipped bundles, and the dependencies you pull in.

headerguard
Audits a site's HTTP security headers, grades them, and generates a Content-Security-Policy to match.
mailguard
Grades a domain's SPF, DKIM, DMARC, and MTA-STS, and with --fix writes the records for you.
bundle-leak
Scans a deployed site's JavaScript and source maps for leaked secrets and recoverable source.
slopcheck
Scores dependency supply-chain risk using OSV advisories, typosquat detection, and secret scanning.
provenance
Verifies PyPI PEP 740 attestations and checks for starjacking before a package lands on your machine.

Content & AI Security

01

Reveal the text a page is hiding from you, and the instructions it is hiding from a model.

unseen
Surfaces hidden text and prompt-injection payloads — zero-width characters, Unicode tricks, invisible PDF layers.

System Hardening

01

Measure a machine against the controls that actually change the outcome.

harden-check
Audits Windows security posture and, for each gap it finds, tells you exactly how to close it.

How these are built

  1. Zero dependenciesThe standard library first. Fewer moving parts, a smaller attack surface, nothing to install on an air-gapped machine.
  2. Offline by defaultAnalysis never needs the network. What does reach out — advisory feeds, DNS — is explicit and optional.
  3. ReproducibleEvery result can be checked by hand. No hidden model, no telemetry, nothing you cannot audit.
  4. TestedEach instrument carries its own suite. A change that breaks behaviour breaks a test first.
  5. One job eachSmall tools that compose into a workflow, never a single monolith you must adopt whole.
  6. Read the sourceShort enough to read in a sitting. Trust is earned by legibility, not asserted in a README.
