The toolkit

Small, auditable tools that each do one job well — composable across the full defensive workflow.

🔬 Malware Analysis & Reverse Engineering

Pull configs, find injected code, unpack droppers, judge drivers.

↗
unmask
Config extractor for the AsyncRAT / DcRat / VenomRAT family — AES + PBKDF2, HMAC-verified.
 ↗
kira-scan
PE triage with a pure-Python YARA engine — strings, conditions, pe/math/hash modules.
 ↗
ghost-hunter
Live memory scanner — finds injected and hollowed code by walking thread stacks.
 ↗
unwrap
Dropper unpacker for .lnk, .hta, and HTML-smuggling — without executing the payload.
 ↗
driver-guard
BYOVD analyzer — flags the vulnerable-driver capabilities attackers abuse.

🕵️ DFIR & Threat Intelligence

Hunt logs and traffic, turn reports into structured intel.

↗

Engineering principles

Why these tools behave the way they do.

Zero-dependency by designStandard library first. Fewer moving parts, a smaller attack surface, nothing to install on an air-gapped box.
Offline-firstAnalysis never requires the network. What reaches out is explicit and optional.
ReproducibleEvery result can be checked by hand. No magic, no hidden model, no telemetry.
TestedEach tool ships with its own suite. A change that breaks behaviour breaks a test first.
One job eachSmall tools that compose, not a monolith.
Trust nothing, verify everythingRead the source. Confirm the output. Assume nothing in between.
